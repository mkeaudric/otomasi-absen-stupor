# Absensi-Stupor
API otomasi absensi stupor UNPAR (Program untuk yang suka lupa absen (kayak gw)

Tech Stack :
- Lib : Selenium, FastAPI
- Env : GC Run, GC Scheduler (Jadwal fix), GC Tasks (mobile HTTP Shortcuts)

## Cara Pakai
### Desktop
Masukan jadwal fix ke GC Scheduler

## Deploy ke GC
Upload : Dockerfile, absenStupor.py, .dockerignore, requirements.txt


### Mobile 
Jam di luar jadwal utama pakai **HTTP Shortcuts**
1. Bikin variabel baru
2. Bikin shortcut
    - URL : link deploy GC
